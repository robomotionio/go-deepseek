Every session is forgotten — and the balance is deliberately changed, from to , so the model cannot cheat.

If run 1’s lesson had memorized the number, run 2 could answer without dialing — and we could never tell learning from parroting. A memorized figure is now stale and would be caught; the only way to be right is to really call and hear it fresh. What survives the reset is the route — in a file the agent cannot read, replayed into the next session before it wakes.
